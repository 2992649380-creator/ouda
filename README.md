# OUDA Foundry Website

English trade website for Jinan Ouda Casting Material Co., Ltd.

## Structure

`dist/` contains the editable HTML, CSS, JavaScript, images, fonts, and product brochure. This is a static site; no build step or package installation is required.

## Preview and deployment

Serve `dist/` with any static HTTP server. For hosting, set the publish/output directory to `dist`.

The inquiry form currently provides frontend interactions only. Connect a real receiving service before using it to collect inquiries.

This snapshot excludes local Git history and internal hosting configuration.
